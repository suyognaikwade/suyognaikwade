### Professional Overview

Principal Full-Stack Architect and Cloud/DevOps Engineer specializing in large-scale multi-tenant SaaS platforms, distributed cloud infrastructure, and intelligent automation. Experienced in steering systems from conceptual design through automated delivery, high-concurrency scaling, and enterprise production operations.

- **Systems Architecture**: Design of decoupled microservices, modular monoliths, and resilient event-driven architectures utilizing Feature-Sliced Design (FSD).
- **Multi-Cloud Infrastructure**: Provisioning and managing workloads across Amazon Web Services (AWS), Google Cloud Platform (GCP), Microsoft Azure, and Oracle Cloud Infrastructure (OCI).
- **DevOps & Quality Engineering**: End-to-end continuous integration and deployment (CI/CD) pipelines featuring automated testing, static code analysis with SonarQube, containerization with Docker, and orchestration with Kubernetes.
- **Applied AI & Agentic Systems**: Integration of state-of-the-art Large Language Models (LLMs), local runtime inference, retrieval-augmented generation (RAG), and autonomous developer workflows.
